# 2048++ 增强版游戏

经典2048游戏的增强版本，包含难度选择、排行榜、成就系统、分享功能、主题切换等特性。

## 特色功能

- 🎮 **难度选择**：支持 3×3、4×4、5×5 三种难度
- 🏆 **本地排行榜**：保存玩家分数记录，支持排名
- 🏅 **成就系统**：4个成就可解锁（首次通关、满分挑战、速度之王、时光倒流）
- 🎵 **音效功能**：方块移动、合并、成就解锁音效
- 🌓 **主题切换**：深色/浅色模式自由切换
- ️ **撤销功能**：支持多步撤销（最多100步）
- 📤 **分享功能**：一键复制成绩分享文本
- 🎭 **作弊模式**：输入特定方向序列激活作弊模式
- 💾 **自动保存**：游戏状态自动保存到本地存储
- 📱 **响应式设计**：完美适配桌面和移动端
- 📄 **个人简历页面**：展示个人信息和项目经验

## 快速开始

### 方法一：直接打开
直接双击打开 `index.html` 文件即可在浏览器中开始游戏！

### 方法二：使用本地服务器
```bash
npm install http-server -g
http-server -p 3000
# 或者
node server.js
# 访问 http://localhost:3000
```

### 方法三：Python 服务器
```bash
python -m http.server 8080
# 访问 http://localhost:8080
```

## 游戏玩法

- **键盘控制**：使用方向键 (↑↓←→) 控制方块移动
- **触屏控制**：滑动屏幕控制方块移动
- **ESC键**：暂停/继续游戏

## 成就系统

| 成就 | 描述 | 解锁条件 |
|------|------|----------|
| 🎉 首次通关 | 合成2048方块 | 在游戏中合成一个2048方块 |
| 💯 满分挑战 | 合成4096方块 | 在游戏中合成一个4096方块 |
| ⚡ 速度之王 | 60秒内合成1024 | 在游戏开始后60秒内合成1024 |
| 🔄 时光倒流 | 使用撤销功能10次 | 累计使用撤销功能达到10次 |

## 作弊模式

输入以下方向序列激活作弊模式：
```
左 → 左 → 右 → 右 → 右 → 右 → 左 → 左
```

激活后所有方块将变成128，快速跳过游戏前期！

## 技术栈

- 纯前端实现：HTML5 + CSS3 + JavaScript
- 本地存储：localStorage
- 响应式设计：CSS Grid + Flexbox
- 音效系统：Web Audio API
- 动画效果：CSS3 Animations
